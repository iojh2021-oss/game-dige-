# چرخهٔ نمادین این منطق

یک پروژهٔ گرافیکی وب برای نمایش خودکار یک چرخهٔ نمادین با حال‌وهوای بازی‌های مزرعه‌ای 2D.

> توجه: این پروژه عمداً از عبارت «چرخهٔ نمادین این منطق» استفاده می‌کند. محتوای آن یک مدل هنری/تفسیری است و ادعای علمی دربارهٔ انسان، سیارات، سرنوشت یا معنویت ندارد.

## ایده
به‌جای اینکه بازیکن مزرعه را کنترل کند، دنیا خودش در یک Auto Loop حرکت می‌کند و ناظر فقط چرخه را می‌بیند:

کِتِر → حُخما → بیناه → حِسِد → گِووراه → تیفرت → نتسح → هود → یسود → ملکوت → بازگشت به کِتِر

## ویژگی‌ها
- بدون بازیکن و بدون مأموریت؛ فقط ناظر
- چرخهٔ خودکار و بی‌نهایت
- مرحلهٔ فعال با نور و حرکت
- توقف، ادامه، شروع دوباره و کنترل سرعت
- رابط کاملاً راست‌به‌چپ و فارسی
- فونت فارسی Vazirmatn با fallback
- گرافیک 2D مستقل، بدون وابستگی به دارایی بازی‌های تجاری
- توضیح صریح دربارهٔ نمادین بودن مدل

## اجرا
